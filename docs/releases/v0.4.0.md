# MiniCodex v0.4.0 — Human-in-the-loop

[简体中文](v0.4.0.zh-CN.md) · **English**

MiniCodex v0.4.0 turns the local Web workspace into a supervised coding workflow. Users can choose a permission mode per task, inspect every caution-level operation before it runs, review the resulting diff, and then accept or reject the complete task.

## Highlights

- Per-task **Review**, **Auto**, and **Read-only** permission modes.
- Review-mode decisions for **Allow once**, **Allow for task**, and **Deny**, with bounded and redacted operation previews.
- Cooperative cancellation and timeout handling while the Agent waits for a decision.
- Persistent approval request and resolution events in the Trace audit trail.
- Complete-diff and per-file navigation before task-level **Accept / Reject**.
- The same deterministic Runtime, validation gates, and checkpoint rollback semantics in both CLI and Web UI.

## Security boundary

- Deterministic hard blocks cannot be overridden by an approval.
- Read-only mode removes side-effecting tools from the model schema and independently rejects edits, processes, validation processes, and dependency installation at execution time.
- Approval previews use an explicit argument allowlist and redact sensitive values.
- The UI remains loopback-only and protects mutations with Host, same-origin, and session-token checks.
- CLI behavior remains backward compatible and uses Auto mode unless a UI task selects another mode.

## Quality evidence

- 708 deterministic project tests passed locally.
- CI covers Python 3.11, 3.12, and 3.13, plus package construction.
- The wheel was installed outside the source tree and verified to report version `0.4.0` and include the Web UI assets.
- The Review approval, audit Trace, per-file Diff, Accept, Reject, and permission-mode flows were exercised in a real browser.

The release Benchmark is intentionally executed after publication so the published result measures the immutable release commit. Its public report and machine-readable summaries are attached to the [GitHub release](https://github.com/wz13814990585-sudo/Mini_codex/releases/tag/v0.4.0).

## Current limitations

- One Agent task runs at a time, and in-progress state remains process-local.
- Accept / Reject is task-atomic; partial acceptance of individual files or hunks is not yet available.
- Approval grants last only for the current task and are not persisted across service restarts.
- Read-only and safety enforcement are application-level controls, not a kernel-level container sandbox.
