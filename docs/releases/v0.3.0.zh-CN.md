# MiniCodex v0.3.0 — 本地 Web 工作台

**简体中文** · [English](v0.3.0.md)

MiniCodex v0.3.0 在现有确定性 Runtime 之上增加了首个可实际使用的浏览器工作台，让仓库浏览、Agent 执行、验证活动和变更审查进入同一个本地产品界面。

## 主要能力

- 通过 `minicodex ui --workspace /path/to/project` 启动无额外前端依赖的本地 Web 工作台。
- 文件树和搜索、代码预览、Git Diff、Agent Chat、实时任务阶段与 Trace 活动终端。
- 使用现有 checkpoint rollback 的任务级 **Accept / Reject**；Reject 不依赖 `git reset`，也不会覆盖 checkpoint 后的外部修改。
- Stop 按钮通过 Runtime 的协作式取消机制阻止后续模型步骤与工具调用。
- 中文和英文界面切换；任务原文不会因界面语言而改变。

## 安全边界

- HTTP 服务只允许监听本地回环地址。
- 变更型请求需要随机会话令牌，并校验 Host 与同源边界。
- 响应启用 CSP、frame、MIME 和 Referrer 安全头。
- 文件预览受工作区边界、大小、二进制、符号链接和敏感凭证规则保护。
- UI 复用与 CLI 相同的 Agent、安全、验证和完成门禁，不维护第二套执行逻辑。

## 质量证据

- 689 项确定性项目测试通过。
- CI 覆盖 Python 3.11、3.12 和 3.13。
- Python 编译检查、JavaScript 语法检查和 Git 空白检查通过。
- wheel 在源码目录外完成安装验证，并确认包含 UI 静态资源与 `minicodex ui` 命令。
- 390 px、768 px 和桌面宽度完成响应式检查，浏览器控制台无警告或错误。

## 当前限制

- 一次只运行一个 Agent 任务。
- Diff 审查与 Accept / Reject 以整个任务为粒度，尚未提供逐命令审批。
- 活动终端是只读 Trace 视图，不是任意 shell。
- 消息、运行中状态和 Reject checkpoint 仍是进程内状态；关闭服务后不能续跑未完成任务。
- 本地服务不是远程多人应用，也不是内核级容器沙箱。
