# MiniCodex v0.2.0 — Resume-Ready 产品 Alpha

**简体中文** · [English](v0.2.0.md)

MiniCodex v0.2.0 将项目从 Agent 研究原型推进为可安装、可演示的本地编程 CLI 产品。

## 主要能力

- 产品命令：`minicodex run`、`minicodex chat` 和 `minicodex doctor`。
- 兼容 OpenAI Chat Completions 的模型配置，以及安全的 API Key 处理。
- 离线和 JSON 环境诊断，并提供显式启用的在线连接检查。
- 确定性完成门禁、仓库感知验证、受限执行、checkpoint rollback 和结构化 trace。
- 兼容原有交互命令和 `--prompt` 模式。
- 可复制的五分钟计算器演示，覆盖功能修改与回归测试流程。

## 快速开始

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cp .env.example .env

minicodex doctor
minicodex run "修复失败测试并验证结果" --workspace /path/to/project --output verbose
```

`minicodex doctor --connect` 会显式发送一次最小模型请求，可能产生少量费用。普通 `minicodex doctor` 保持离线。

## 兼容性

已有的 DeepSeek 环境变量继续可用。新的 provider-neutral 变量为：

- `MINICODEX_API_KEY`
- `MINICODEX_BASE_URL`
- `MINICODEX_MODEL`

## 已知限制

- 交互会话仍是单进程，进程崩溃后不能恢复未完成任务。
- 浏览器交互验证依赖可选的 Playwright 和 Chromium。
- 工作区内通过安全策略的操作默认自主执行，尚未提供逐命令人工审批。
- 模型与网络波动仍可能影响任务成功；自动验证不能替代代码审查。
