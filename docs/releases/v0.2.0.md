# MiniCodex v0.2.0 — Resume-Ready Product Alpha

MiniCodex v0.2.0 turns the project from an agent research prototype into an
installable, demonstrable CLI product for local coding workflows.

## Highlights

- Product commands: `minicodex run`, `minicodex chat`, and `minicodex doctor`.
- OpenAI Chat Completions-compatible provider configuration with safe API-key handling.
- Offline and JSON environment diagnostics, plus an opt-in live provider check.
- Deterministic completion gates, repository-aware validation, sandboxed execution,
  checkpoint-based rollback, and structured traces.
- Backward compatibility with the original interactive command and `--prompt` mode.
- A copyable five-minute calculator demo for feature-edit and regression-test workflows.

## Quick start

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cp .env.example .env

minicodex doctor
minicodex run "修复失败测试并验证结果" --workspace /path/to/project --output verbose
```

`minicodex doctor --connect` performs an explicit minimal provider request and may
incur a small model charge. Plain `minicodex doctor` stays offline.

## Compatibility

Existing DeepSeek environment variables remain supported. The new provider-neutral
variables are:

- `MINICODEX_API_KEY`
- `MINICODEX_BASE_URL`
- `MINICODEX_MODEL`

## Known limitations

- Interactive sessions are single-process and cannot resume after a process crash.
- Browser interaction validation requires optional Playwright and Chromium installs.
- Safe in-workspace operations run autonomously; per-command human approval is not yet
  available.
- Model and network variability can still affect task success. Automated validation
  reduces risk but does not replace code review.
