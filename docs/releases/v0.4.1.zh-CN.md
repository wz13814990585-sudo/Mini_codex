# MiniCodex v0.4.1 — 回归验证证据修复

**简体中文** · [English](v0.4.1.md)

MiniCodex v0.4.1 修复了 v0.4.0 Benchmark V1 R2 中发现的内部完成门禁缺陷。两个重构任务已通过独立隐藏 oracle，但通过的语义回归检查没有转为账本 proof，导致 Agent 继续工作直到耗尽步数。

## 修复内容

- 归一化语义、静态网页和浏览器验证结果时保留原定的 `acceptance` 或 `regression` 用途。此前结果一律被标为 `acceptance`，因此账本会拒绝回归检查的证据。
- 保留 check 身份、当前编辑版本、足够证据强度及 Agent 自建测试限制等原有 proof 条件；没有关闭验证门禁。
- 为解析器提取和 Web 脚本提取的完成链新增确定性回归测试。

## 验证结果

- 710 项确定性项目测试通过；离线 VibeBench 15/15 通过。
- 使用 DeepSeek `deepseek-v4-flash`、温度 0、每题最多 20 步，单轮定向复测的 **2/2** 个隔离 fixture 均通过：`refactor_extract_parser` 与 `refactor_extract_web_script`。两项独立隐藏 oracle 均通过，内部完成状态均为 `ready`，都没有耗尽步数。
- 本次定向复测衡量的是发布元数据提交前的代码提交 `ff427d2e040c173fc12ced545d95c09d3be206d0`；它**不是**完整 30 项 Benchmark 的复测，也不替代已公开的 v0.4.0 成绩。
